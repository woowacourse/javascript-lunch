### 테스트

- E2E 테스트
  - 카테고리 필터링 테스트
    - [ ] 기본 상태에서 모든 음식점이 보이는지 확인한다.
    - [ ] 사용자가 각 필터를 선택하면 각 카테고리 음식점만 보인다.
    - [ ] 사용자가 '한식' → '중식' 필터를 선택하면 중식 카테고리 음식점만 보인다.
    - [ ] 사용자가 '한식' → '전체' 필터를 선택하면 모든 음식점이 보인다.
    - [ ] 필터를 선택했을 때 존재하는 음식점이 없으면 빈화면이 보인다.
  - 정렬 테스트
    - [ ] 기본 정렬이 이름순(가나다순)으로 적용되어 있는지 확인한다.
    - [ ] 사용자가 '거리순' 정렬을 선택하면 가까운 거리순으로 음식점이 정렬된다.
    - [ ] 한식 필터를 적용한 후 '거리순' 정렬을 선택하면 한식 내에서 가까운 거리순으로 정렬된다.
  - 자주 가는 음식점 탭 테스트
    - [ ] 사용자가 특정 음식점에 별을 누르고 자주 가는 음식점 탭을 클릭하면 해당 음식점만 보인다.
    - [ ] 사용자가 아무 음식점도 즐겨찾기하지 않은 상태에서 자주 가는 음식점 탭을 선택하면 빈 화면이 보인다.
    - [ ] 자주 가는 음식점이 여러 개일 때, 하나씩 삭제할 때마다 목록이 정상적으로 업데이트되는지 확인한다.
  - 자주 가는 음식점 추가 테스트
    - [] 사용자가 음식점 리스트에서 별을 누르면 자주 가는 음식점에 추가되고, 자주 가는 음식점 탭을 눌렀을 때 추가한 음식점이 표시된다.
    - [] 사용자가 음식점 상세 모달에서 별을 누르면 자주 가는 음식점에 추가된고, 모달창을 닫고 자주 가는 음식점 탭을 눌렀을 때 추가한 음식점이 표시된다.
  - 음식점 상세보기 테스트
    - [] 음식점을 클릭하면 해당 음식점의 상세 모달이 열린다.
    - [] 닫기 버튼을 누르면 모달이 닫힌다.
    - [] ESC 키를 누르면 모달이 닫힌다.
    - [] 모달 바깥을 클릭하면 모달이 닫힌다.
  - 음식점 삭제하기 테스트
    - [] 사용자가 음식점 상세보기 모달에서 "삭제하기" 버튼을 누르면 음식점이 삭제된다.
    - [] 음식점을 삭제한 후 전체 음식점 리스트에서도 사라졌는지 확인한다.
    - [] 자주 가는 음식점에서 삭제했을 때, 전체 목록에서도 사라지는지 확인한다.
