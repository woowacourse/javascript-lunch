# STEP2 기능 명세서

## 기능 구현

- [ ] 상단 헤더에 "모든 음식점" 과 "자주 가는 음식점" 선택 기능 구현
- 음식점 목록
  - [ ] 카테고리별로 필터링해서 확인할 수 있다.
  - [ ] 이름순/거리순으로 정렬해서 확인할 수 있다.
- 음식점 상세 정보 (모달)
  - [ ] 카테고리, 이름, 거리, 설명, 참고 링크를 확인
  - [ ] 음식점을 삭제 기능
- "자주 가는 음식점"을 추가 및 목록 확인
  - [ ] 음식점 목록에서 자주 가는 음식점을 추가
  - [ ] 음식점 상세 정보에서 자주 가는 음식점으로 추가
  - [ ] 자주 가는 음식점 탭에서 추가한 음식점 목록을 확인
- [ ] 새로고침해도 추가한 정보들이 유지 (localStorage)
- [ ] (Domain) Typescript로 리팩토링
