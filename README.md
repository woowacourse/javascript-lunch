# 점심 뭐 먹지 - STEP2

## 기능 요구 사항

### 화면 구성

- [] Main

  - [x] 음식점 아이템
    - [x] 별 (자주가는 음식점 추가)
  - [] 모든 음식점 탭
  - [] 자주 가는 음식점 탭
  - [] 카테고리 필터링 셀렉트 박스
  - [] 이름순/거리순 정렬 셀렉트 박스

- [] 음식점 상세 모달

  - [] 카테고리 이미지
  - [] 별 (자주가는 음식점 추가)
  - [] 음식점 이름
  - [] 캠퍼스로 부터 거리
  - [] 음식점 설명
  - [] 음식점 링크(누르면 이동)
  - [] 삭제하기 버튼
  - [] 닫기 버튼

- [] 자주가는 음식점 탭
  - [] 음식점 아이템만 존재

<br>

### 기능

- [] 카테고리 별로 필터링 되는 기능
- [] 이름순/거리순으로 정렬되는 기능
- [] 모든 음식점 탭을 누르면 모든 음식점을 보여주는 기능
- [] 자주 가는 음식점을 누르면 별표 표시된 음식점만 보여주는 기능
- [] 음식점 목록에서 자주 가는 음식점 추가하는 기능
- [] 음식점을 클릭하면 음식점 상세정보가 보이는 기능
- [] 음식점 상세 정보에서 자주가는 음식점 추가하는 기능
- [] 새로 고침 해도 추가한 정보들이 유지되는 기능
