## 점심 뭐 먹지?

### 도메인 기능 요구 사항

1. - [x] 음식점 정보를 등록한다.

- 카테고리(select)
  - 카테고리는 한식,중식,일식,아시안,양식,기타 중 하나여야한다
- 이름
- 거리(도보시간)(select)
  - 5, 10, 15, 20, 30중 하나를 선택해야 한다.
- 설명
  - 선택 사항
- 참고 링크
  - 선택 사항

2. - [x] 음식점 정보를 보여준다.

- 리스트 형태로 보여주기
- 모달창 상세보기 형태로 보여주기

3. - [x] 필터 기능이 존재한다.

- 카테고리별 필터 존재
- 거리순/이름순 필터 존재
- 모든 음식점/자주 가는 음식점 필터 존재

4. - [x] 음식점 좋아요 기능
5. - [x] 음식점 삭제 기능
6. - [x] localStorage에 데이터를 저장하여 새로고침해도 데이터가 유지되게 구현

### UI 기능 요구 사항

1. 음식점 목록 화면

- [x] 음식점 추가 버튼을 누르면 모달이 뜬다.
- [x] 등록된 음식점을 리스트로 확인할 수 있다.
- [x] 음식점 리스트를 스크롤을 통해 확인할 수 있다.
- [x] 음식점 리스트를 클릭하면 모달창으로 음식점 상세보기를 할 수 있다.
- [x] 각 음식점마다 즐겨찾기 기능을 사용할 수 있다.
- [x] 세가지 필터에 맞춰서 필터링하여 리스트를 확인할 수 있다.

2. 음식점 추가

- [x] 카테고리를 선택할 수 있다.
- [x] 이름을 입력할 수 있다.
- [x] 거리를 선택할 수 있다.
- [x] 설명을 입력할 수 있다.(선택 사항)
- [x] 참고링크를 입력할 수 있다.(선택 사항)
- [x] `추가하기` 버튼을 클릭했을 때 음식점 목록 화면에 해당 음식점이 추가 된다.

3. 음식점 상세보기

- [x] `삭제` 버튼을 클릭했을 때 음식점을 삭제할 수 있다.
- [x] 해당 음식점에 즐겨찾기 기능을 사용할 수 있다.

### e2e 테스트 항목

**1. 음식점 목록 페이지 테스트**

- [x] 헤더가 정상적으로 로드 되어야 한다.
- [x] 음식점 목록이 정상적으로 로드 되어야 한다.

**2. 음식점 추가 페이지 테스트**

- [x] 필수 필드를 입력하고 등록 하기 버튼을 누르면 마지막 항목으로 식당이 추가된다.
- [x] 각 입력 필드 유효성 검사시 적절한 오류 메시지가 표시된다.

**3. 모달 동작 테스트**

- **등록하기 폼 모달창**
- [x] 메뉴 추가 버튼을 눌렀을때 등록하기 폼 모달창이 열린다.
- [x] 취소하기 버튼을 누르면 모달창이 닫힌다.

- **식당 상세보기 모달창**
- [x] 각 식당의 title을 누르면 해당 식당의 디테일 정보 모달창이 열린다.
- [x] 닫기 버튼을 누르면 모달창이 닫힌다.

- **공통 모달창**
- [x] 모달 바깥 회색창을 누르면 모달창이 닫힌다.

**4. 필터 동작 테스트**

- [x] 선택한 카테고리 별로 필터링 되어 음식점이 로드 되야 한다.
- [x] 선택한 옵션(거리순/이름순) 별로 필터링 되어 음식점이 로드 되야 한다.
- [x] 선택한 즐겨찾기 탭별로 필터링 되어 음식점이 로드 되야 한다.

**5. 좋아요 기능 테스트**

- [ ] 식당 리스트에 있는 별표시를 클릭하면 해당 식당의 별이 채워진다.

**6. 식당 삭제 테스트**

- [ ] 상세보기 모달창에서 삭제를 누르면 해당 식당이 삭제된 리스트가 보인다.
