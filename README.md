## E2E Cypress 테스트

- [x] "자주 가는 음식점" 즐겨찾기 아이콘 클릭 시 "자주 가는 음식점" 으로 추가 및 취소
- [x] "모든 음식점" 및 "자주 가는 음식점" 각 카테고리 선택
  - [x] 모든 음식점 버튼을 클릭하면 모든 음식점이 표시
  - [x] 자주 가는 음식점 버튼을 클릭하면 자주 가는 음식점이 표시
- [x] 레스토랑 상세 정보 모달 테스트
  - [x] 한 레스토랑 선택 시 레스토랑 상세 정보 모달이 띄어진다
  - [x] 레스토랑 상세 정보 모달에서 close버튼을 누르면 모달이 꺼진다.
  - [x] 레스토랑 상세 정보 모달에서 delete버튼을 누르면 모달이 꺼지고 해당 레스토랑이 제거
