## 점심 뭐 먹지?

### 도메인 기능 요구 사항

1. - [x] 음식점 정보를 저장한다.

- 카테고리(select)
  - 카테고리는 한식,중식,일식,아시안,양식,기타 중 하나여야한다
- 이름
- 거리(도보시간)(select)
  - 5, 10, 15, 20, 30중 하나를 선택해야 한다.
- 설명
  - 선택 사항
- 참고 링크
  - 선택 사항

2. - [x] 음식점 정보를 보여준다.
3. - [x] 음식점 목록을 확인할 수 있다

- 음식점을 카테고리 별로 필터링 할 수 있다
- 이름순으로 정렬 할 수 있다
- 거리순으로 정렬 할 수 있다

4. - [x] 음식점을 삭제할 수 있다
5. - [x] 음식점 카드에 별을 누르면 자주가는 음식점으로 추가된다

6. 새로고침해도 추가한 정보들이 유지되어야 한다.

### UI 기능 요구 사항

1. 음식점 목록 화면

- [x] 음식점 추가 버튼을 누르면 모달이 뜬다.
- [x] 등록된 음식점을 리스트로 확인할 수 있다.
- [x] 음식점 리스트를 스크롤을 통해 확인할 수 있다.

2. 음식점 추가

- [x] 카테고리를 선택할 수 있다.
- [x] 이름을 입력할 수 있다.
- [x] 거리를 선택할 수 있다.
- [x] 설명을 입력할 수 있다.(선택 사항)
- [x] 참고링크를 입력할 수 있다.(선택 사항)
- [x] `추가하기` 버튼을 클릭했을 때 음식점 목록 화면에 해당 음식점이 추가 된다.

3. 음식점 상세 정보를 확인할 수 있다

- [x] 음식점 목록에서 카드를 눌렀을때 카테고리,이름,거리,설명,참고링크를 확인할 수 있다

4. - [x] 필터링 된 음식점 목록을 확인할 수 있다
5. 모든음식점/자주가는 음식점 탭 구분

- [x] 자주가는 음식점 탭을 누르면 별을 누른 음식점 목록을 확인할 수 있다.

## e2e 테스트 항목

**음식점 목록 페이지 테스트**

- [x] 헤더가 정상적으로 로드 되어야 한다.
- [x] 탭이 정상적으로 로드 되어야 한다
- [x] 음식점 목록이 정상적으로 로드 되어야 한다
  - [x] 자주 가는 음식점탭 클릭시 즐겨찾기 된 음식점 목록이 나와야한다
  - [x] 모든 음식점탭 클릭시 필터링이 모두 전체일떄 모든 음식점 목록이 나와야한다
- [x] 정렬 기준으로 올바른 정렬이 되어야 한다
  - [x] 카테고리 정렬을 했을때 해당 카테고리 식당만 나와야한다
  - [x] 이름순 정렬을 했을때 이름순으로 정렬되어야 한다
  - [x] 거리순 정렬을 했을때 거리순으로 정렬되어야 한다

**음식점 추가 페이지 테스트**

- [x] 필수 필드를 입력하고 등록 하기 버튼을 누르면 마지막 항목으로 식당이 추가된다.
- [x] 각 입력 필드 유효성 검사시 적절한 오류 메시지가 표시된다.

**모달 동작 테스트**

- 음식점 등록 모달
- [x] 메뉴 추가 버튼을 눌렀을때 모달창이 열린다.
- [x] 취소하기 버튼을 누르면 모달창이 닫힌다.
- [x] 모달 바깥 회색창을 누르면 모달창이 닫힌다.

- 음식점 상세보기 모달
- [x] 음식점 카드를 클릭했을때 상세보기 모달창이 열린다.
- [x] 닫기 버튼을 누르면 모달창이 닫힌다.
- [x] 모달 바깥 회색창을 누르면 모달창이 닫힌다.
- [x] 삭제하기 버튼을 누르면 해당 음식점 정보가 삭제된다.
